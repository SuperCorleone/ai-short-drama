# 03 大纲（第一、二章 · 首集体量）

> 改编原则：对话为主 + 关键 OS 点缀；剔除纯设定叙述，把世界观"演"出来（K-018）；爽点/反转按 K-013 标注。

## 一、整体定位

- 题材：星际科幻 + 末世穿越 + 家庭轻喜剧，爽点是"满级老兵装萌新"的反差。
- 首集钩子：一个从末世死人堆里爬出来的老兵，醒来成了星际时代的恋爱脑"精神小妹"——身份反差 + 她比谁都冷静。

## 二、第一章大纲：醒来（约 2.5–3 分钟）

1. **开场钩子**：睡眠舱中惊醒，气音应答舱门提示（末世习惯：出声会引来丧尸）。——3 秒抓住"这人不对劲"。
2. **世界观落地（演出来，不旁白）**：她打量两个"白色棺材"似的舱体、家用机器人呼吸灯；喝水时 OS 交代：末世摸爬滚打十年，被五级丧尸舔了一口，醒来就成了"人型古董"。
3. **回忆闪回（情绪低点）**：雪夜基地大门，她掩护"骆驼"回撤，被丧尸舔中——穿越瞬间，浴缸中惊醒。
4. **现状清点（轻喜节奏）**：光脑头条（育儿舱/超电磁加农炮机甲/医疗舱）；《星际编年史》播到"星际150年"；OS 吐槽：知识全废，但干净的水、食物、热水澡让她"舍不得再死一回"。
5. **人物悬念（章末钩子）**：记忆里反复出现一张白毛男孩的脸——母胎单身的老兵大为震惊："都星际时代了还有恋爱脑？！"交代原身：18岁、第一军校准新生、父母一周后归、弟弟集训中。窗外星兽虫族的威胁点到为止。

## 三、第二章大纲：深夜厨房与弟弟（约 2.5–3 分钟）

1. **承接**：凌晨 02:30，看资料饿了，赤脚下楼，感应灯随脚步亮灭（科幻细节演出来）。
2. **小爽点①·冰箱**：拉开塞满新鲜果蔬的冰箱，眼睛发亮——"末世里这一顿值半个月贡献点"。洗水果、煮面卧蛋，拒绝料理机器人代劳："食物这件事怎么能假手他人！"机器人落寞返回充电（萌点）。
3. **干饭蒙太奇**：煮饭十分钟吃饭五分钟，打着饱嗝嘬营养液——老兵的满足感。
4. **人物揭示（镜子）**：路过镜子，拨弄黑白染发，OS 吐槽"审美独特"——交代原身"精神小妹"外形由来：为模仿白毛染发、浓妆武装自己，源于被亲戚孩子轻蔑的童年。情绪由嘲转怜。
5. **章末钩子·首次交锋**：大门电子音，近两米的弟弟王开宇夜归，姐弟对视。弟弟狐疑她半夜干饭、惊讶她素颜；她紧张到嗓子发干。弟弟习惯性等她"开刺"，她却只淡淡一句"早点休息"。弟弟挠头嘀咕："今天竟然没有刺我？是还没睡醒吗？"——**反转收束**：家人都不知道，壳子里已经换人了。
